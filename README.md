## 🔧 Featured Project

### [Sports ETL Pipeline](https://github.com/DarriousBedford/sports-pipeline)
An end-to-end batch pipeline that pulls real NFL/NBA/MLB game data from a public API, loads it into **BigQuery** via an idempotent stage-and-merge pattern, transforms it with **dbt** into team performance and rolling scoring-trend models, and is orchestrated with **Prefect**. Validated with a pytest unit-test suite and dbt data-quality tests, with CI running on every push via **GitHub Actions**.

`Python` · `BigQuery` · `dbt` · `Prefect` · `GitHub Actions` · `pytest`
